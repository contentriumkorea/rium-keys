# CONTENTRIUM Keys 2.0.5

## 변경 내용

- Premiere Pro에서 시간 눈금자를 클릭한 뒤 한글 상태의 P 단축키가 작동하지 않던 경로를 수정했습니다. 기존 코드에서 실패를 재현하고, 같은 동작이 설치된 2.0.5에서 첫 P로 펜 도구를 선택하는 것을 확인했습니다.
- 일부 작업 환경의 내부 라디오 그룹·대화상자 필터 때문에 단축키 영역을 인식하지 못하던 경로를 보완했습니다. 확인된 타입·처리 함수·포커스 관계만 허용하며, 알 수 없는 입력 영역을 단축키 영역으로 간주하지 않습니다.
- 2.0.3의 첫 단축키 처리 순서 보완을 포함합니다. 2.0.1~2.0.4에서 같은 설치 파일로 업데이트할 수 있습니다.
- After Effects의 실제 입력·단축키·입력 복귀를 검증했습니다. 아래 시험에서는 추가 결함이 재현되지 않아 에펙 전용 코드는 변경하지 않았습니다.

## 실제 앱 검증 — 2026-11-02

시험은 Windows x64에서 설치된 **2.0.5.0** 입력기로 진행했습니다. 원본 작업 문서는 편집하지 않았으며, 한/영 키를 누르지 않고 영문 키 위치를 실제 키 입력으로 전달했습니다. 텍스트 값을 프로그램으로 넣는 동작을 한글 조합 시험으로 계산하지 않았습니다.

| 프로그램 | 확인한 동작 | 결과 |
| --- | --- | --- |
| Premiere Pro 26.5.2.5 | 프로젝트·효과 검색에 한글 입력 → 시간 눈금자 클릭 → 첫 P | 펜 도구 선택 |
| Premiere Pro 26.5.2.5 | 검색칸 복귀, 한글 재입력, 다른 창 전환 후 눈금자의 첫 P | 완결된 반복 시험 2회 통과 |
| After Effects 26.5.0.89 | 프로젝트 검색의 한글 입력 → 타임라인 → 첫 H | 손 도구 선택 |
| After Effects 26.5.0.89 | 효과 검색 → 타임라인, 프로젝트 검색 → 컴포지션, 다른 창 전환 후 첫 H | 한글 유지와 손 도구 선택 확인 |
| After Effects 26.5.0.89 | 컴포지션의 텍스트 레이어에 한글 입력 → 타임라인 → 첫 H → 검색칸에서 한글 재입력 | 텍스트 내용·손 도구·검색칸 복귀 확인 |

별도로 Premiere의 변경 전 실패 상태에서 시간 눈금자의 내부 입력 경로를 읽기 전용으로 확인했습니다. 에펙은 실제 불린 입력기 버전과 7개 지원 모듈의 파일 해시도 확인했습니다.

**한계:** 시험한 경로와 버전에 대한 결과입니다. 모든 수정키 조합·패널·프로그램·미래 버전, 장시간 또는 매우 빠른 연속 입력은 보장하지 않습니다. Premiere의 내부 필터 변경분은 정적 분석·자동검사로 확인했지만, 과거에 발생한 모든 필터 조합을 이번 실기에서 재현하지는 못했습니다. Studio One의 과거 실기 기록은 이전 개발 빌드 기준입니다.

## 자동검사·설치 검증

- x64/x86 네이티브 검사 묶음 **25개 통과**.
- DVA 판별 **234개**, 메타데이터 **97개** 검사 통과. 새 시간 눈금자 A–Z 26개 양성 사례는 변경 전 실패, 변경 후 통과했습니다. 잘못된 타입·콜백·토큰·처리 함수와 변조된 가상 함수 슬롯은 거부합니다.
- 설치 스크립트의 타입 모델 **41개 검사 통과**. 운영체제 레지스트리 복구 시험을 실제로 수행했다는 뜻은 아닙니다.
- 이 PC의 2.0.4 → 2.0.5 설치가 종료 코드 **3010**으로 성공했습니다. 설치 파일 18개 해시와 양 아키텍처 COM 경로를 확인하고, 다시 실행한 Premiere·After Effects에서 2.0.5.0 로딩을 확인했습니다. 강제 재부팅하지 않았습니다.

## 설치와 업데이트

1. [최신 설치 파일](https://github.com/contentriumkorea/rium-keys/releases/latest/download/CONTENTRIUM-Keys-Setup.exe)을 받습니다.
2. 작업을 저장하고 편집 앱을 종료한 뒤 설치 파일을 **일반 실행**합니다. 처음부터 관리자 권한으로 실행하지 마세요.
3. 등록 단계의 Windows 관리자 확인창에서 **예**를 누릅니다.
4. 설치 후 편집 앱을 다시 실행하고, 필요하면 **Windows + Space → CONTENTRIUM Keys**를 선택합니다.

새 설치·구버전 제거·복구는 [설치 안내](installation.md)를 따릅니다. Microsoft 한국어 입력기는 복구용으로 유지하세요. 설치 파일은 약 **664KB**이며 게시자 코드 서명이 없습니다. 포터블·온라인 설치기·자동 업데이트는 이 버전에 포함하지 않습니다. 일반 설치 과정에 타이핑 시험은 없습니다.

```text
15629c4f8da5f5d9c8b0d634d03ad223e3f74ec7afa62900c34e4cac8bd85f22
```

[SHA256SUMS.txt](https://github.com/contentriumkorea/rium-keys/releases/latest/download/SHA256SUMS.txt)와 비교할 수 있습니다. 소스 코드 ZIP은 설치 파일이 아닙니다.
