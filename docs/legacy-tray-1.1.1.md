# RIUM Keys 1.1.1 — historical tray utility

아래는 구형 유틸리티의 설명입니다. 새 CONTENTRIUM Keys 입력기 설치는 [현재 안내](installation.md)를 사용하세요.

한글 입력 상태를 유지하면서 PC 전반의 인식 가능한 비텍스트 영역에서 단축키를 전달하는 Windows 트레이 유틸리티입니다.

[설치 파일 다운로드](https://github.com/contentriumkorea/rium-keys/releases/latest/download/RIUM-Keys-Setup.exe)

## 설치와 사용

1. 설치 파일을 실행합니다. 현재 Windows 사용자 계정에 설치되며 관리자 권한은 필요하지 않습니다.
2. 별도 창이나 알림 없이 작업표시줄 알림 영역에 RIUM Keys 아이콘이 나타납니다. 숨겨진 아이콘 영역에 있을 수도 있습니다.
3. 아이콘을 우클릭하면 기능 켜기/끄기, Windows 시작 시 실행, 자동 업데이트, 업데이트 확인, 종료를 사용할 수 있습니다.

Windows 로그인 시 자동 실행과 자동 업데이트는 기본으로 켜집니다. 컴퓨터의 로그인 화면에서는 동작하지 않습니다. Windows 자체의 시작 앱 설정에서 사용 안 함으로 바꾸면 자동 실행이 차단될 수 있습니다.

앱은 실행 후 약 10초 뒤와 이후 6시간 간격으로 새 버전을 확인합니다. 게시자의 RSA 서명과 설치 파일의 SHA-256·크기를 확인한 뒤 조용히 설치하고 다시 실행합니다. 업데이트 실패는 트레이 메뉴에 표시하고 다음 주기에 재시도합니다. 설치 위치와 설정은 유지됩니다.

제거는 Windows 설정 → 앱 → 설치된 앱 → RIUM Keys에서 할 수 있습니다. 제거 시 자동 실행 등록도 삭제됩니다.

## 지원 범위와 검증 상태

Adobe 앱 목록 제한을 없애고 현재 활성화된 Windows 프로그램을 대상으로 동작합니다. 표준 버튼 및 접근성 정보로 확인된 비텍스트 컨트롤·읽기 전용 문서 영역에서 영문자 및 일부 기호 키를 전달합니다. After Effects와 Premiere Pro에는 기존 편집 영역 감지도 유지합니다. Ctrl/Alt/Windows 조합은 원래 입력을 그대로 통과시킵니다.

입력란, 비밀번호, 편집 가능한 문서, 터미널, 한글 이름으로 항목을 찾는 목록·트리, 분류할 수 없는 자체 제작 캔버스에서는 원래 입력을 유지합니다. 한/영 상태를 변경하지 않습니다. 모든 앱·게임·사용자 지정 단축키를 지원한다는 뜻은 아닙니다. 관리자 권한 앱이나 별도 키 입력 방식을 사용하는 앱에는 동작하지 않을 수 있습니다.

클릭·Tab·검색창 열기·한영 전환 직후에는 오래된 판정으로 글자를 가로채지 않도록 잠시 원래 입력을 통과시킵니다. 전환 후 최소 75ms 및 새 영역 확인 전에는 첫 단축키가 보정되지 않을 수 있습니다. 일부 앱의 최초 접근성 확인에는 1초 이상 걸릴 수 있지만 키 입력을 기다리게 하거나 모아 두지 않습니다. 느린 응답은 별도 감시 프로세스로 분리하고, 오래된 결과는 사용하지 않습니다.

자동 검사에서는 일반 컨트롤과 WPF의 같은 창 안에서 텍스트/비텍스트 전환, 단축키 눌림·뗌 전달, 입력란 및 비밀번호 우회, 전환 직후 글자 우회, 업데이트 무결성을 확인합니다. 단축키 전달 시험의 한글 상태는 시험용 값이며 모든 실제 IME/앱 호환성을 증명하지 않습니다. 초기 After Effects 시험 이후의 종합 실사용 검증과 Premiere 실제 한글 단축키 검증은 여전히 남아 있습니다.

1.1.1에서는 Premiere Source Monitor 인식을 추가하고, 키를 누른 채 반복할 때 새 판정을 기다리다가 반복 입력이 완전히 취소되는 문제를 고쳤습니다. Adobe 패널 이름과 텍스트 상태를 한 번의 상위 영역 조회로 확인해 중복 조회를 줄였습니다. 같은 창 핸들에서 Timeline → Program Monitor → Source Monitor로 바뀌는 시험용 UI와 반복 중 입력란 전환을 검사했습니다. 이 시험은 실제 Premiere가 아니므로 제보된 Premiere 멈춤과 화면 위 작은 표시의 해결 여부는 별도 실사용 확인이 필요합니다.

구름 입력기는 macOS 입력기 자체를 구현한 프로젝트이고 RIUM Keys는 기존 Windows 입력기를 유지하는 보조 프로그램입니다. 구름의 코드나 입력기 엔진을 복사한 제품이 아니며 동일한 호환성을 보장하지 않습니다.

## 개인정보

키 입력 내용이나 문서 내용을 서버로 전송하지 않습니다. 네트워크는 GitHub 업데이트 확인·다운로드에 사용합니다. 설정은 현재 사용자 레지스트리, 업데이트 캐시는 `%LOCALAPPDATA%\RiumKeys`에 저장합니다. 오류 발생 시 같은 폴더의 `last-error.log`에 최근 오류 한 건을 기록합니다.

## 개발

Windows x64, .NET 10 SDK, NSIS 3.13이 필요합니다. NSIS를 `tools/nsis-3.13`에 준비한 뒤 `./build.ps1`로 검사·실행 파일·설치 파일을 빌드합니다. 실행용 .NET 런타임은 설치 파일에 포함됩니다. `./test-processes.ps1`는 백그라운드 실행 및 감시 프로세스 복구/종료를 검사합니다.

배포 메타데이터는 `./sign-release.ps1`로 생성합니다. 서명용 개인 키는 저장소에 포함하지 않습니다. `src/update-public.pem`은 업데이트 검증용 공개 키입니다.
