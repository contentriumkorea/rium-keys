# CONTENTRIUM Keys 설치·복구 안내

대상: **2.0.0 · Windows x64 · 두벌식 한글**. 별도 .NET 런타임은 필요하지 않습니다. Windows ARM64·32비트 운영체제는 지원 대상으로 검증하지 않았습니다.

## 다운로드와 준비

[CONTENTRIUM-Keys-Setup.exe 다운로드](https://github.com/contentriumkorea/rium-keys/releases/download/v2.0.0/CONTENTRIUM-Keys-Setup.exe). `Source code.zip`은 설치 파일이 아닙니다. `update.json`은 구형 유틸리티 호환용이므로 따로 받지 않아도 됩니다.

설치 파일은 현재 코드 서명이 없습니다. 게시자를 확인할 수 없다는 표시가 나올 수 있으며 배포 페이지의 `SHA256SUMS.txt`로 파일 SHA-256을 대조할 수 있습니다.

1. 한국어 언어 팩과 Microsoft 입력기가 있어야 합니다. 새 설치 전에는 현재 입력기를 **한국어 Microsoft 입력기**로 선택합니다.
2. 처음 설치할 때 기본 입력 방법도 한국어 Microsoft 입력기로 설정합니다. Windows 설정 → 시간 및 언어 → 입력 → 고급 키보드 설정 → 기본 입력 방법 재설정에서 확인합니다. 일반 영문 키보드만 선택된 경우 복구 상태를 저장할 수 없어 중단할 수 있습니다. Microsoft 입력기는 삭제하지 않습니다.
3. 작업을 저장하고 편집 프로그램을 종료합니다. 설치기는 앱을 강제로 닫지 않습니다. 열려 있던 앱은 이전 입력기 파일을 계속 사용하므로 설치 후 재실행해야 합니다.
4. 설치할 사용자 계정에서 Setup을 **일반 실행**합니다. 관리자 권한 실행 메뉴는 사용하지 않습니다. 등록 단계에서만 Windows 관리자 확인을 요청합니다.

## 설치 순서

1. `CONTENTRIUM-Keys-Setup.exe` → 다음 → MIT 라이선스 확인 → 설치.
2. Windows 관리자 확인창에서 **예**를 누릅니다.
3. 자동 점검이 끝나면 **마침**을 누릅니다. 한글 입력이나 V 키 시험은 요구하지 않습니다.
4. 작업 프로그램을 다시 실행합니다. **Windows + Space → CONTENTRIUM Keys**로 선택할 수 있습니다.

자동 점검은 파일 해시, 입력기 등록·사용 설정, 64비트·32비트 DLL의 실제 로딩과 필수 인터페이스를 확인합니다. 작업 문서에 글자를 입력하거나 사용 중인 창을 조작하지 않습니다. 프로그램별 입력·단축키 시험은 개발 검증 항목이며 일반 설치 과정에 포함되지 않습니다.

표시: **가 = 한글**, **A = 영어/직접 입력**, **CK = 입력기 선택**. 우클릭 메뉴의 입력기 사용을 끄면 직접 입력합니다. 별도 설정 앱이나 자동 실행 EXE 없이 Windows가 선택된 입력기를 불러옵니다.

## 기존 버전에서 설치

| 기존 설치 | 진행 |
| --- | --- |
| 없음 / RIUM Keys 1.1.1 유틸리티 | 새 설치. 자동 점검 성공 후 기존 유틸리티 제거 |
| 직전 개발 빌드 10 | 같은 EXE에서 2.0.0으로 업데이트 |
| 그보다 오래된 입력기 | 설치된 앱에서 기존 입력기 제거 → 새 설치 |
| CONTENTRIUM Keys 2.0.0 | 현재 파일·등록·로딩을 확인하고 중복 설치 생략 |

업데이트·제거에는 저장된 복구 정보가 필요합니다. 다른 사용자 계정의 설치이거나 복구 기록이 없으면 덮어쓰지 않고 중단합니다.

## 문제가 있을 때

- **관리자 확인 취소**: 설치가 완료되지 않습니다. 설치 파일을 다시 실행하세요. 이전 시도 상태 오류가 나오면 아래 로그를 확인합니다.
- **자동 점검 실패**: 새 설치를 확정하지 않습니다. 업데이트는 이전 등록 경로와 이름·아이콘을 복구하고, 새 설치는 등록과 입력 상태 복구를 시도합니다. 성공 화면이 없으면 완료로 간주하지 않습니다.
- **기존 폴더·복구 상태 오류**: 이전 시도의 파일을 보존하기 위해 중단한 상태입니다. DLL이나 레지스트리를 직접 지우지 말고 로그를 확인합니다. 실패한 설치 폴더를 자동으로 덮어쓰지 않습니다.
- **예전 아이콘이 남음**: 해당 앱을 다시 실행합니다. Windows가 아이콘을 캐시한 경우 로그아웃·로그인으로 갱신됩니다.
- **단축키가 안 됨**: 현재 입력기 선택을 확인하고 프로그램 이름·버전, 입력칸에서 작업 영역으로 이동한 순서를 기록합니다. [지원 범위](../README.md#지원-범위)를 참고하세요.

설치 로그: `%LOCALAPPDATA%\Contentrium\KeysSetup`

복구 기록: `%LOCALAPPDATA%\Contentrium\RIUM Keys\Recovery`

설치 폴더: `C:\Program Files\RIUM Keys\2.0.0`. 기존 등록·설정 호환을 위해 내부 폴더 이름은 유지합니다.

제거: Windows 설정 → 앱 → 설치된 앱 → **CONTENTRIUM Keys → 제거**. 설치 전 입력기로 되돌린 뒤 등록을 제거합니다. 실행 중인 앱이 사용 중인 DLL은 바로 삭제되지 않을 수 있습니다. 개인 설정과 복구 기록은 보존합니다.

업데이트는 GitHub의 새 설치 파일로 진행합니다. 자동 업데이트 기능은 포함하지 않습니다. 검증 환경과 결과는 [2.0.0 배포 기록](release-2.0.0.md)에 정리합니다.
