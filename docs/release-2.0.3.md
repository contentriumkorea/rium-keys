# CONTENTRIUM Keys 2.0.3

## 변경 내용

- Premiere Pro의 빈 타임라인에서 기존의 검증된 내부 경로가 더 짧게 시작하는 경우도 단축키 영역으로 인식합니다. 임의의 창이나 알 수 없는 내부 경로를 단축키 영역으로 간주하지 않습니다.
- 한글 조합이 끝났지만 이전 입력창 참조가 남은 경우, 첫 단축키 판정 전에 그 참조를 정리합니다. 작성 중인 한글, 보류된 입력, 진행 중인 편집과 타이머는 정리 대상에서 제외합니다. 참조 해제 중 새 입력이 시작되면 상태를 다시 확인합니다.
- 2.0.1과 2.0.2에서 같은 설치 파일로 직접 업그레이드할 수 있습니다. 기존 한/영 상태와 복구 정보를 보존합니다.

## 다운로드·설치

1. [CONTENTRIUM-Keys-Setup.exe](https://github.com/contentriumkorea/rium-keys/releases/latest/download/CONTENTRIUM-Keys-Setup.exe)를 받습니다.
2. 작업을 저장하고 편집 프로그램을 종료합니다.
3. 설치 파일을 일반 실행하고, 등록 단계의 Windows 관리자 확인창에서 **예**를 누릅니다.
4. 편집 프로그램을 다시 실행합니다. Windows에서 재시작을 요청하면 편한 시점에 재시작합니다. 설치기는 작업 앱이나 Windows를 강제 종료하지 않습니다.

새 설치·복구 방법은 [설치 안내](installation.md)를 참고하세요. `SHA256SUMS.txt`로 설치 파일의 해시를 확인할 수 있습니다. 설치 파일은 게시자 코드 서명이 없으며, 포터블 실행·온라인 설치·자동 업데이트 기능은 제공하지 않습니다. 일반 설치 과정에는 타이핑 시험이 없습니다.

## 검증한 범위

- 64비트·32비트 네이티브 계약 시험 총 25개 묶음 통과.
- 키 처리 시험은 각 아키텍처에서 114개 검사 통과. 완료된 입력 대상의 선행 정리, 보류 입력 보존 및 참조 해제 중 재진입을 포함합니다.
- DVA 판별 시험 58개 통과. 새 8단계 양성 경로와 잘못된 깊이·타입·토큰·콜백·화면·표본·이미지·수정키 거부를 확인합니다.
- 설치 스크립트 계약 39개 통과. 타입이 있는 값과 별칭 모델을 사용하며, 이 시험을 운영체제 레지스트리의 실제 동작 검증으로 표현하지 않습니다.
- 기존 2.0.1에서 설치 EXE 사전 점검과 실제 2.0.3 업그레이드가 성공했습니다. 설치 과정에서 양 아키텍처의 등록·로딩·CK 로고 및 상태 보존을 자동 확인했습니다. 설치는 재시작 필요 코드 3010으로 끝났으며 강제 재부팅하지 않았습니다.

**미확인:** 이 버전 설치 후 Premiere·After Effects에서 실제 한글 입력 → 첫 단축키 → 한글 입력 복귀를 끝까지 재검증하지 못했습니다. 자동 검사 및 설치 성공을 실제 앱 문제의 완전 해결이나 모든 프로그램·미래 버전 지원으로 해석하지 마세요. 증상이 남으면 앱 버전, 입력칸 종류, 이동한 패널과 첫 키/두 번째 키의 차이를 알려주세요. 입력 내용이나 작업 문서를 보낼 필요는 없습니다.

지원 계약은 Premiere Pro 26.5.2.5, After Effects 26.5.0.89의 검증된 모듈 및 Studio One 6.6.4.102451에 한정됩니다. 지원되는 일부 화면의 일반 A–Z 단축키가 대상이며, 모든 패널·수정키 조합·새 버전에서의 동작을 보장하지 않습니다. Microsoft 한국어 입력기는 복구용으로 유지하세요.
